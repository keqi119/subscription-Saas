# 纯电主义 · 微信小程序前端

这是可以导入微信开发者工具的**原生小程序源码工程**，不是 HTML 原型。默认以本地 Mock 运行。包含四个主页面、选车/预设套餐/申请、最终方案确认、用车服务、资料及账户记录；后台尚未准入时可独立开发界面。

本批次不代表真实登录、后台交易、支付、电子签或真机联调已经通过。已配置“纯电主义”的 AppID，前端不包含 AppSecret。四个 Tab 的基础页面已在微信开发者工具现场显示；Nightly 曾出现首次白屏，Stable 2.02.2608070 下也有启动延迟和路由超时，随后可自行显示，尚未确认彻底修复。最新证据和验收范围见 [VALIDATION.md](VALIDATION.md)。

## 工程位置

```text
apps/miniprogram/
```

以上为仓库内相对路径。后台模块依据为 `f8ed944030646bb697c4724e9071b1151e64e5ef`，2026-09-24 发布准备时核对远端 `main` 仍为此提交。小程序是该基线之后新增的独立前端。

## 导入微信开发者工具

1. 选择“导入项目”，目录选择上述工程根（包含 `project.config.json` 的目录），不要选 `src` 或整套后台仓库。
2. 配置中 `miniprogramRoot` 为 `src/`，`appid` 为“纯电主义”的 AppID，项目显示名称为“纯电主义”。请使用拥有该小程序开发权限的微信账号导入；复用工程时替换为自己有权限的 AppID，不要把 AppSecret 写入前端。填写 AppID 不代表开发权限、登录、支付或发布已经验收。
3. 不使用云开发。本工程无 npm 运行时依赖；微信端无需执行“构建 npm”。JavaScript/WXML/WXSS 直接从 `src` 读取。
4. 保持 `src/config.js` 的 `mode: 'mock'`、`apiBase: ''`。点击编译，记录工具版本、基础库版本、AppID 类型和编译结果。
5. 验证四 Tab、选车、申请审核、最终方案、用车工单及记录；通过“我的 → 演示设置”切换场景。Mock 不发业务网络请求，也不需要关闭请求域名校验。

当前可继续前端与 Mock 开发。若首次编译后首页白屏，可先切到“选车”再返回首页继续界面调试；这是已验证的临时恢复步骤，不代表首次启动异常已修复。不要把本项目连接到旧 `subscription_saas` 或临时对外开放后台端口。

## 本机检查与源码预览

需要 Node.js 22 或以上。在工程根执行；首次克隆后先安装开发检查所需依赖：

```powershell
npm ci --workspaces=false
npm test
npm run check
npm run compile:templates
npm run preview
```

- `npm test`：Node 测试直接运行实际服务、Page JS 和受控 wx 替身，另含模板编译与预览服务器检查。
- `check`：检查 JS/JSON、页面/组件注册、事件、资源及内部引用。
- `compile:templates`：使用微信团队发布的 `miniprogram-compiler@0.2.3` 附带 wcc/wcsc 编译真实 WXML/WXSS。该包的编译器版本较早，只是模板验证证据，不能替代当前开发者工具/基础库。
- `preview`：启动仅绑定 `127.0.0.1` 的源码预览，默认 `18931`，占用时在随后 9 个本地端口内选择并输出实际地址。终端 `Ctrl+C` 停止。每次改源码后重启以刷新快照。

预览直接使用本工程 Page/Component/服务源码、编译后的 WXML 与 WXSS。浏览器桥只支持本工程使用的基础交互，强制 Mock 并阻止请求/上传；附件选择会产生一份合成元数据，不读取实际文件。它明确标为“源码预览 · 非微信模拟器”。微信原生相册、胶囊、安全区、字体缩放、网络与生命周期行为仍需在工具/真机检验。

`node scripts/package.cjs` 可生成交付目录与文件清单，位于 `.artifacts/delivery/`，明确排除 `node_modules`、`.artifacts`、`project.private.config.json` 和 `config.local.js`。自制 PNG 可选用 Python/Pillow 运行 `scripts/create-assets.py` 重建；运行小程序不需要 Python。

## 页面与可体验流程

| 页面/模块 | 本批交付                                                              |
| --------- | --------------------------------------------------------------------- |
| 首页      | 新客、申请中、用车中下一步；推荐车辆、流程说明与 FAQ                  |
| 选车/详情 | 品牌、关键词筛选；车辆事实、车况资料、预设套餐、完整条件；不可售状态  |
| 申请/进度 | 联系信息和说明校验、提交审核、防重复、取消；确认/拒绝有版本的最终方案 |
| 用车      | 当前订阅、账单与里程待办；救援、事故、里程复核、交接                  |
| 我的      | 本地示例资料、当前申请、8 类记录、隐私/服务说明与演示设置             |
| 记录      | 订阅订单、合同、账单、支付、押金、权益、通知、服务；列表/详情/空态    |
| 服务表单  | 位置、描述、联系方式、附件元数据；不会派车或联系供应商                |
| 里程/交接 | 不覆盖已确认里程；证据阅读、确认/异议与独立签署状态                   |

### 演示场景

- **新客**：浏览目录、填写资料、提交申请。申请只进入审核，押金待确认，不生成正式订单。
- **申请审核中**：查看申请进度或取消。
- **待确认最终方案**：核对完整使用条件和版本，确认后仅生成本地“待签约”订单；拒绝不生成订单。
- **用车中**：查看合成的当前订阅、账单/押金等记录，体验服务与交接表单。

场景切换会重建对应的演示记录；请先完成当前体验。故障选项“正常/空数据/加载失败”不会把状态误报成真实后台结果，可随时恢复。重置只清理本工程的 Mock 存储键。

请使用虚构姓名和手机号，不输入真实证件。附件仅保留名称、大小、类型等元数据，不保留临时图片路径、不上传。车辆图片是本工程自制示意图；所有样例价格、里程、押金和“已签署/已支付”示例记录都不构成真实事实。支付/签署说明按钮不会改写交易成功状态。

## 后台就绪后的连接方式

`src/config.js` 是唯一模式开关，用户界面或缓存不能切到真实后台：

```js
module.exports = Object.freeze({
  mode: "api",
  apiBase: "http://127.0.0.1:3310", // 仅在专用 API 与该入口已验收后填写
  requestTimeout: 10000,
  mockDelay: 160,
  storageKey: "ev-subscription:miniprogram:mock:v1",
  sourceVersion: "f8ed944030646bb697c4724e9071b1151e64e5ef"
});
```

先由后台负责人完成专用数据库迁移、权限与 Schema 核验，以及 API 连接专用库的身份核验，再进行真实目录请求。该地址仅供电脑本机；手机中的 localhost 不指向电脑。这里不自动修改微信域名校验、证书、Docker 网络或防火墙。非本机环境只接显式 HTTPS 源地址（不含 `/api` 后缀）。

API 模式当前只调用匿名 catalog GET。错误保留为错误，绝不回退样例；客户身份与所有写接口明确返回“尚待联调”，不发送请求。服务端现有 Cookie、公众号 OAuth、H5 支付和签署不能直接当成小程序登录/交易能力。字段映射及后续交接见 [API-HANDOFF.md](API-HANDOFF.md)。
