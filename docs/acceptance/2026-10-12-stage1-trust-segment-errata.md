# Stage 1：信任材料分段实施与勘误

本轮按已批准的最小设计完成 C1/C2 代码和 C3 控制准备。尚未发起新的正式 RC；局部通过不等于 R3 CLOSED，也不等于阶段 1 已收口。

## 实际改进

- 同一 H1 owner 只通过固定官方 gh 获取一次 GitHub/Public Good 根材料。proof、receipt、当前及历史 admission 仍分别验签；授权、撤销和 run/job 状态继续实时回读。
- 材料由当前进程私有持有；期限取原 Execute 截止、已认证元数据最早到期、取得后 1200 秒的最小值。路径/文件身份、字节、时钟或操作绑定异常即永久失效；不自动刷新、不跨 RC 复用通过结论。
- 错误记录明确输入类别、公开摘要、操作引用、退出码、信号和耗时。Node → Python → PowerShell 的实际离线传递已验证；保留主错误及独立清理错误，不保存原始 stderr、命令参数或凭据。
- 八文件控制由单一 descriptor 渲染，候选/source/build/run/job/ref/摘要/Execute 起点/截止及各段预算集中校验。新控制全部保持 PREPARED_STOP；既有 ACTIVE 和 once 原件未改写。

## 对历史勘误的约束

27 次 RC 的原始复盘：[逐例勘误](D:/Projects/stage1-rc-audit-20261012/stage1-s1-rc-errata.html)。[逐例准入映射](../../.superpowers/sdd/2026-10-05-stage1-h1-snapshot-host/candidate-23e4b82-rc-audit-reentry/gate.json) 保留原事实，不把新探针成功反写为历史失败首因。

| 类型                                    | 定性与处置                                              | 下轮检查/复用边界                                                                                           |
| --------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 时序差错、重复验签                      | 已确认编排/代码成本；不能据此断言每次网络超时的唯一原因 | 从实际 Execute 起点计算；收集→冻结→启动连续；30/15/95/120/1200/90/600 秒各自预算不混用；同 owner 复用根材料 |
| 绑定旧源码、旧正文摘要或过期签名        | 代码/控制输入瑕疵，不属于环境抖动                       | descriptor 精确绑定且拒绝旧候选文本；源码变化只重做依赖该源码的成果，旧签名不转移                           |
| 历史用例状态残留                        | 确定性环境状态问题，不属于随机抖动                      | 消费槽/锁/session/清理分开回读；保留历史 consumed/UNKNOWN，不能靠改 UUID 消除                               |
| 不稳定定位、历史 admission 被标成 other | 诊断代码缺口                                            | 使用实际读取原件的摘要和上下文 ref；不猜失败 selector；既有 gh 诊断也纳入固定收集                           |
| TUF 外部请求停止                        | 历史首因仍 UNKNOWN；重复根轮换成本已确认                | 失败停在材料获取段，不重建整个发布链；当前可达或一次验签通过不能证明网络永不失败                            |

## 本轮新发现与修正

| 发现                                                   | 分类                                     | 修正及验证                                                                               |
| ------------------------------------------------------ | ---------------------------------------- | ---------------------------------------------------------------------------------------- |
| 私有 reader 遇到原生夹具的 0664 文件或公共 `/tmp` 祖先 | 测试环境准备错误，非业务缺陷、非网络抖动 | 原生测试树去组写入并使用其私有 TMPDIR；实际 IMPORT/历史接线通过                          |

| ZIP 关闭后再读取条目                                   | 新控制代码缺陷                           | 在 `with ZipFile` 内读取；真实 ZIP 解包回归通过                                          |
| 清理错误覆盖/丢失主错误，新的 TUF 原因未穿透解析器     | 新诊断代码缺陷                           | 保留原错误及 cleanupCode；包装边界验证通过                                               |
| 收集器可能另存原始 stdout/stderr                       | 新诊断代码缺陷                           | 失败仅留允许的状态、耗时、字节数与摘要；秘密标记注入检查通过                             |

| WSL 公开根获取失败                                     | 环境相关失败，深层原因未确认             | 留存 TUF_CLIENT/GITHUB/ROOT 与退出码；未归因为抖动，不继续盲目重试                       |
