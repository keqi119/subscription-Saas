## 证据和结论等级

- **C（确认）**：实际失败及对应代码/输入/复现足以定位所述缺陷；仍不把未观察的下游结果补成成功。
- **R（同类复现）**：已复现并修正一个同类缺陷，但原失败缺少决定性现场证据，不能声称唯一历史根因。
- **U（未明）**：错误和残留状态已确认，具体触发原因未证明。后续通过不能倒推原失败原因。
- **P（执行前拦截）**：静态审核或准备阶段发现；不能计入真实发布失败，也不能据此声称运行验证完成。

主要证据为 [H1 执行台账](../../.superpowers/sdd/2026-10-05-stage1-h1-snapshot-host/progress.md)（下称 **P**，以下标明行号）及 [10 月 1 日状态记录](2026-10-01-stage1-r3-delivery-status.md)。被忽略目录中的证据属于本机保留材料，不随 Git 文档自动交付；原失败记录不得覆盖。原始字节摘要和 canonical JSON 摘要分别记录，不互换。

**性质与证据等级是两个维度。** “代码瑕疵”包括产品、发布适配器及诊断脚本的确定性逻辑错误；“编排错误”包括使用顺序、冻结输入和授权时间绑定错误；“环境兼容”指稳定的宿主路径/挂载/API 形态差异；“环境抖动”需实际瞬态网络/资源/服务证据。泛化错误、后一次通过、耗时不同都不充分，无法归因时标“未明”。同一条可以有多层原因，但不能把编排错误包装成不可控环境抖动。

## 本轮执行补记（2026-10-07 15:40 UTC 后）

- **E07／P，代码与编排预算缺陷：** Reader 签名、Reader archive、公开控制安装的旧预算未覆盖准备和清理，已在执行前准备专用副本，保留原件。完整预算见 [后续调用清单](../../.superpowers/sdd/2026-10-05-stage1-h1-snapshot-host/dispatch-forward-followup-37581130311-reviewed.md)。这些属于提前拦截，不计为真实链新增失败；未跑长时间超时压力测试。
- **E23／P，冻结输入编排缺陷：** 旧清单先调用 prepare-reader，再调用内部再次 prepare 的签名生成器，会按两次 `issuedAt` 得到不同授权 digest。改为仅生成一次完整输入包，签名和归档均取同目录原件；不能靠重签或放宽 digest 校验补救。此事没有发生过期签名被接受。
- **E20／C，实际推进：** seq0→1 转换与独立回读完成；原 Writer 失败保留。恢复目录 Execute、Readback、Seal、Readback 完成，三项清理均为 true；[最终回读](../../.superpowers/sdd/2026-10-05-stage1-h1-snapshot-host/writer-recovery-fa9a222d-actual/readback-final.stdout.json) raw SHA-256 为 `c617a5dac0e4b4ea4648e1bbdcead8164db5e8326cc57fddb8cdbe99607a968d`。这证明本次 Writer 封存，不代表 Reader custody、R3 或阶段 1 完成。
- **E21／U，定位边界：** 新诊断草案区分 prompt 前后 EOF、SIGHUP/SIGTERM 与子进程退出，并先保存首因、再保存清理事实；本地短检查使用 socketpair，不能冒充真实 PTY/SSH。旧断连原因仍未明。旧 5b 半完成 import 保留，新 ref 草案尚未获批或预留。
- **本地检查夹具瑕疵（C，非生产链故障）：** 转换的首次夹具遗漏中间目录权限、第二次夹具遗漏模拟 subprocess 常量；修正仅在夹具，原失败输出保留。不能把这两次设置失败计作产品 RED，也不能归为环境抖动。最终限定文件系统检查通过，不外推 H1 运行结论。

- **E06／P，本地字节处理缺陷：** 新引用审查包使用 Windows `os.open` 写入时未显式指定 `O_BINARY`，导致 LF/CRLF 转换及落盘哈希不一致；这是本地编排工具缺陷与稳定平台行为，不是 H1 环境抖动。修正后仅对实际落盘字节重算清单和交叉哈希，旧版本保留；不运行远端来验证换行。
- **E24／P，前提核对：** 新 sourceFresh 预留器也继承了漏算挂载/清理的旧预算，已执行前拦截。快照初始模板即使语法通过，仍缺真实 sourceFresh gate、适用的 producer v2 前置原件及实际 deployment 绑定；必须先填真实依赖，不能靠旧 RAM 读回或 fixture 填空。见 [来源核对](../../.superpowers/sdd/2026-10-05-stage1-h1-snapshot-host/producer-prerequisite-provenance-37431923399.md) 的字段边界与末尾前向裁定；旧候选记录只供语义参考，不能替代本候选结果。
